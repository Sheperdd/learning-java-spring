# Java Spring + Delivery Resources

## Knowledge

### Spring
- [Spring Boot reference documentation](https://docs.spring.io/spring-boot/index.html)
  The primary source for Boot features, auto-configuration and properties. Use for: anything Boot-specific; always check versions against it.
- [Spring Framework reference: Core (IoC container)](https://docs.spring.io/spring-framework/reference/core.html)
  The authoritative explanation of beans, DI, scopes, AOP and proxies. Use for: project 01 and 07, and any "why does Spring do this" question.
- [spring.io Guides](https://spring.io/guides)
  Short official tutorials, one feature each. Use for: project starting points (e.g. "Building REST services with Spring" for project 02).
- [Spring Initializr](https://start.spring.io)
  Generates new projects and shows the current Boot and Java versions. Use for: every `/new-project`.
- [Baeldung](https://www.baeldung.com)
  Deep, practical articles on nearly every Spring topic. Use for: focused how-tos once the official docs have given the concept. Check the article's Boot version.

### Java
- [dev.java Learn](https://dev.java/learn/)
  Oracle's official modern-Java tutorials (records, sealed types, pattern matching). Use for: Java language features.
- *Effective Java* (3rd ed.), Joshua Bloch
  The classic book of Java best practices (immutability, equals/hashCode, exceptions). Use for: the "why" behind the Java baseline.

### Testing
- [Testcontainers for Java](https://java.testcontainers.org)
  Real Postgres/Kafka in tests. Use for: project 03+ integration tests.

### Git, GitHub, CI/CD
- [Pro Git book](https://git-scm.com/book/en/v2)
  Free and authoritative. Use for: how git really works (commits, branches, rebase vs merge).
- [GitHub Actions documentation](https://docs.github.com/en/actions)
  Use for: workflow syntax, path filters, environments, secrets, GHCR publishing.
- [GitHub flow](https://docs.github.com/en/get-started/using-github/github-flow)
  The branch → PR → merge loop this workspace follows.
- [Conventional Commits](https://www.conventionalcommits.org)
  The commit message convention used here.
- [trunkbaseddevelopment.com](https://trunkbaseddevelopment.com)
  Why teams that ship often keep branches short. Use for: the delivery track's "how professionals do it" talk.

## Wisdom (Communities)
- [r/SpringBoot](https://www.reddit.com/r/SpringBoot/) and [r/learnjava](https://www.reddit.com/r/learnjava/)
  Use for: sanity-checking designs and asking "is this how people really do it?"
- [Spring on Stack Overflow (spring-boot tag)](https://stackoverflow.com/questions/tagged/spring-boot)
  Use for: specific errors. Search before asking.
